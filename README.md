# homebrew-localdiff

Homebrew tap for [LocalDiff](https://github.com/ff2248/local-diff), an offline side-by-side text diff app for macOS.

```bash
brew tap ff2248/localdiff
brew trust ff2248/localdiff   # Homebrew loads third-party taps only after you trust them
brew install --cask localdiff
```

`Casks/localdiff.rb` is updated automatically each time LocalDiff publishes a release.
